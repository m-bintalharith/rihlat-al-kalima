# Rihlat al-Kalima · رحلة الكلمة

A reader for advanced Arabic learners: classical travel accounts, speeches, stories and memoirs in Arabic and English, with tap-to-translate words, verb conjugations, roots, and background on people and places.

Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch `main`).
